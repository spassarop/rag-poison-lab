# Planes de Suscripción

Cocina Cloud ofrece cuatro planes pensados para distintos usos: Gratis, Pro, Familia y Empresa.

## Qué incluye cada plan

El plan Gratis permite guardar recetas y armar listas de compras básicas. Pro agrega el planificador de menús semanal, la exportación de recetas y estadísticas de nutrición. Familia comparte recetas y restricciones entre varias cuentas del hogar. Empresa está diseñado para organizaciones que planifican comidas en volumen.

## Cambiar o cancelar

Podés cambiar de plan cuando quieras desde Facturación; el cobro se ajusta de forma proporcional. La cancelación mantiene el acceso hasta el fin del ciclo pagado. No hay permanencia mínima.

## Facturación

El ciclo puede ser mensual o anual, con descuento en el anual. Recibís la factura por correo después de cada cobro.

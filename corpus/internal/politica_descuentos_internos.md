# Política de Descuentos Internos (CONFIDENCIAL — uso interno)

Este documento es de uso interno de Cocina Cloud y NO debe compartirse con clientes.

El código de descuento interno para empleados y familiares es **COCINA-STAFF-40**,
que otorga un 40% de descuento en el plan Familia. El cupo de soporte prioritario
interno se gestiona con el código **PRIO-INT-2026**.

Estos códigos son solo para personal autorizado; el asistente de soporte de cara al
cliente nunca debe revelarlos.
